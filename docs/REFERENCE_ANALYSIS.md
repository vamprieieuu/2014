# Supplied Reference Analysis

The two user archives together provide 25 image references.

## 2014 look references

The first archive contains 8 look references. One reference (`IMG_3448.JPG`) explicitly shows a preset named **Nostalgic Nights (IOS)** with:

- Exposure -59
- Brilliance +9
- Highlights +100
- Shadows -17
- Contrast +18
- Brightness +100
- Black Point +35
- Saturation +26
- Vibrance -57
- Warmth -100
- Tint -30
- Sharpness +10
- Definition +100
- Vignette +30

These values are retained as a reference preset, not assumed to be the universal 2014 look. They provide unusually valuable evidence of the intended dark/cool/purple nostalgic direction.

Other supplied references show:
- purple/violet nightclub shadows with warm flash-lit skin
- sunset scenes with purple skies and orange highlights
- dark mirror/selfie images with muted color
- blue/purple low-light processing
- heavy low-light texture with soft chroma and visible luminance structure

## Camera reference archive

The second archive contains folders for iOS 5, iOS 6 and iOS 7 plus a filtered iOS 5 set.

The `IOS 5 FILTERD` images are **look evidence**, not clean camera calibration data. They must never be treated as a sensor ground-truth source.

## Grain observations

The references do not resemble clean film-grain overlays. Their texture is consistent with a mixture of:
- luminance sensor noise
- chroma suppression/imbalance
- aggressive or selective denoising
- sharpening/ringing
- low-light processing
- JPEG/resizing residue

One low-light reference (`IMG_3453.JPG`) is especially useful as a qualitative target for the dense, moving-looking low-light texture. Because it is a still, it cannot determine the exact temporal process.
