# Camera Model Requirements

## Profiles

iPhone 5, 5s, 6, 6s, 7, 7 Plus, 8, 8 Plus.

## Each profile controls

- sensor color response
- white balance tendencies
- tone curve
- highlight roll-off/clipping
- shadow behavior
- local tone mapping / HDR character
- luma noise
- chroma noise
- noise reduction
- sharpening/ringing
- lens softness
- distortion
- vignetting/shading
- chromatic aberration
- grain/noise defaults

## UI

Main:
- Camera Model dropdown
- Profile Strength

Advanced groups:
- Exposure
- Basic Tone (Brightness, Contrast, Highlights, Shadows, Whites, Blacks)
- Curves
- Levels
- Color Response
- Detail
- Lens
- Processing / Noise

The profile sets defaults. All controls remain editable.
